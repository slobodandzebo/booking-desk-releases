# Booking Desk – releases

Installable builds of **Booking Desk**, a WordPress plugin by ESDRepairLab: one admin page for all JetAppointments bookings.

Each [release](../../releases) has the plugin zip `booking-desk-<version>.zip`. Sites with Booking Desk installed read the latest release from here and show it under *Plugins → Updates*.
